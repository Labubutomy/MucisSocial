# Playback Queue Service

Сервис отвечает за управление очередями воспроизведения для любых контекстов (группы, совместные плейлисты, live-сессии). Он предоставляет gRPC API, сохраняет состояние в PostgreSQL и гарантирует корректную конкуррентную обработку запросов `GetNextTrack`.

## ✨ Возможности

- Очередь на основе контекста (`context_type` + `context_id`), пригодная для групп, плейлистов, live-сессий.
- Переключение вперёд/назад без пересчёта позиций — курсор двигается по монотонному `position`.
- Удаление конкретного трека (`RemoveTrack`) с сохранением разрежённых позиций.
- Единый формат элементов очереди/истории: в ответах передаём только `track_id`, порядок определяется самим списком.

## 🔌 gRPC API

| RPC                | Описание                                                                     |
| ------------------ | ---------------------------------------------------------------------------- |
| `EnqueueTrack`     | Добавляет трек в указанную очередь.                                          |
| `RemoveTrack`      | Удаляет первое вхождение трека в очереди (по `track_id`).                    |
| `ListQueue`        | Возвращает ближайшие будущие элементы (порядок ≈ реальному воспроизведению). |
| `GetCurrentTrack`  | Возвращает трек на текущей позиции курсора (последний проигранный).          |
| `GetPrevTrack`     | Сдвигает курсор на предыдущую позицию и возвращает найденный трек.           |
| `GetNextTrack`     | Переводит курсор вперёд и возвращает новый текущий трек.                     |
| `CreateQueue`      | Создаёт новый контекст очереди и выдаёт `context_id`.                        |
| `ListPlayedTracks` | Возвращает историю: сначала последний проигранный трек, далее прошлые.       |
| `ClearQueue`       | Сбрасывает очередь и текущую позицию.                                        |

### Пример вызова через grpcurl

```bash
grpcurl -plaintext \
  -d '{"context":{"context_type":"group","context_id":"f3..."},"track_id":"6a..."}' \
  localhost:50056 playback.queue.v1.PlaybackQueueService/EnqueueTrack
```

## ⚙️ Конфигурация

| Переменная     | Назначение                      | Значение по умолчанию                                                        |
| -------------- | ------------------------------- | ---------------------------------------------------------------------------- |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgres://postgres:postgres@localhost:5432/playback_queue?sslmode=disable` |
| `GRPC_PORT`    | Порт gRPC-сервера               | `50056`                                                                      |

## 🧭 Контексты и инициализация

- Только пользовательские контексты (`context_type = "user"`) создаются лениво при первом `EnqueueTrack`/`GetNextTrack` — сервис сам создаст состояние, если его ещё нет.
- Для всех остальных типов контекст нужно создать заранее через `CreateQueue`. Если попытаться работать с отсутствующей очередью, gRPC вернёт ошибку `NOT_FOUND (queue not found)`.

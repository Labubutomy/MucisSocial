# Групповые рекомендации для комнат

## Описание

Функция группового матчинга рекомендаций позволяет генерировать музыкальные рекомендации для группы пользователей, слушающих музыку вместе в одной комнате. Алгоритм находит баланс между музыкальными предпочтениями всех участников, чтобы создать плейлист, который понравится большинству.

## Ключевые особенности

### 1. Агрегация профилей пользователей
- Объединяет музыкальные вкусы всех участников комнаты
- Учитывает жанровые предпочтения каждого пользователя
- Агрегирует историю прослушиваний артистов
- Отслеживает, какие треки уже слышали участники

### 2. Умный скоринг треков
Алгоритм оценки учитывает:
- **Жанровое соответствие** (вес 3.0): Насколько жанры трека популярны в группе
- **Популярность артистов** (вес 2.5): Насколько артист популярен среди участников
- **Глобальная популярность** (вес 1.5): Общая популярность трека среди всех пользователей
- **Свежесть** (вес 0.5): Бонус за новые релизы
- **Разнообразие** (вес 2.0): Поощрение треков, которые не слышало большинство

### 3. Фильтрация
- Исключает треки, которые слышало более 50% участников
- Поддерживает фильтрацию по явному контенту
- Позволяет ограничить рекомендации по жанрам
- Можно фильтровать по дате релиза

## API Endpoint

### POST `/recommendations/group`

Генерирует групповые рекомендации для списка пользователей.

**Request Body:**
```json
{
  "user_ids": ["user1", "user2", "user3"],
  "limit": 20,
  "filters": {
    "exclude_explicit": true,
    "genres": ["rock", "pop"],
    "fresh_days": 30
  }
}
```

**Response:**
```json
{
  "tracks": ["track_id_1", "track_id_2", "track_id_3"],
  "group_size": 3,
  "user_ids": ["user1", "user2", "user3"],
  "description": "Group recommendations that balance preferences across all users in the room"
}
```

## Примеры использования

### 1. Базовые групповые рекомендации

```bash
curl -X POST http://localhost:8080/recommendations/group \
  -H "Content-Type: application/json" \
  -d '{
    "user_ids": ["alice", "bob", "charlie"],
    "limit": 10
  }'
```

### 2. С фильтрами по жанрам

```bash
curl -X POST http://localhost:8080/recommendations/group \
  -H "Content-Type: application/json" \
  -d '{
    "user_ids": ["alice", "bob", "charlie"],
    "limit": 20,
    "filters": {
      "genres": ["rock", "alternative", "indie"]
    }
  }'
```

### 3. Только свежие треки без явного контента

```bash
curl -X POST http://localhost:8080/recommendations/group \
  -H "Content-Type: application/json" \
  -d '{
    "user_ids": ["alice", "bob", "charlie"],
    "limit": 15,
    "filters": {
      "exclude_explicit": true,
      "fresh_days": 14
    }
  }'
```

## Ограничения

- Максимум 50 пользователей в одной группе
- Минимум 1 пользователь в группе (хотя рекомендуется минимум 2 для группового матчинга)
- Максимум 100 треков в одном запросе

## Алгоритм работы

1. **Загрузка профилей**: Получение профилей всех пользователей из группы
2. **Агрегация**: Объединение предпочтений в единый групповой профиль
3. **Генерация кандидатов**: Использование агрегированного профиля для поиска потенциальных треков
4. **Фильтрация**: 
   - Исключение треков, знакомых большинству (>50%)
   - Применение пользовательских фильтров
5. **Скоринг**: Оценка треков с учетом групповых предпочтений
6. **Ранжирование**: Сортировка по итоговому скору
7. **Лимитирование**: Возврат топ-N треков

## Интеграция с сервисом сессий

Для использования в контексте музыкальных комнат:

```javascript
// Пример использования на фронтенде
async function getGroupRecommendations(roomId) {
  // 1. Получить список участников комнаты
  const participants = await getRoomParticipants(roomId);
  const userIds = participants.map(p => p.userId);

  // 2. Запросить групповые рекомендации
  const response = await fetch('/api/v1/recommendations/group', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      user_ids: userIds,
      limit: 30,
      filters: {
        exclude_explicit: false
      }
    })
  });

  const data = await response.json();
  return data.tracks;
}
```

## Технические детали

### GroupProfile структура
```go
type GroupProfile struct {
    UserIDs           []string        // Список ID участников
    GenreListenCount  map[string]int  // Агрегированные жанровые предпочтения
    ArtistListenCount map[string]int  // Агрегированные предпочтения артистов
    ListenedTracks    map[string]int  // Трек ID -> количество пользователей, которые слышали
    TotalUsers        int             // Общее количество пользователей
}
```

### GroupScorer
Специализированный скорер для групповых рекомендаций:
- Нормализует предпочтения по количеству участников
- Балансирует между популярными и нишевыми треками
- Поощряет разнообразие для группового опыта

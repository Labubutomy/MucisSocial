## 2. Pipeline генерации рекомендаций

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Recommendation Pipeline                          │
└─────────────────────────────────────────────────────────────────────┘

    User Request
         │
         ▼
┌────────────────────────────────────────────────────────────────────┐
│  STEP 1: Candidate Generation                                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐           │
│  │TopGenres     │  │TopArtists    │  │Fallback       │           │
│  │Generator     │  │Generator     │  │Generator     │           │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘           │
│         │                  │                  │                     │
│         └──────────────────┴──────────────────┘                     │
│                            │                                       │
│                            ▼                                       │
│                  ┌──────────────────┐                              │
│                  │ Candidate Set    │                              │
│                  │ (deduplicated)   │                              │
│                  └──────────────────┘                              │
└────────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────────────────┐
│  STEP 2: Hard Filtering                                            │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐           │
│  │Already       │→ │Explicit      │→ │Genre/        │           │
│  │Listened      │  │Filter        │  │Freshness     │           │
│  └──────────────┘  └──────────────┘  └──────────────┘           │
└────────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────────────────┐
│  STEP 3: Scoring                                                   │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │  HeuristicScorer (или MLScorer)                           │   │
│  │  score = genreAffinity + artistAffinity +                  │   │
│  │          popularity + freshness                            │   │
│  └────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────────────────┐
│  STEP 4: Ranking                                                   │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │  Sort by score (descending)                                │   │
│  │  Optional: ReRanker (diversity, etc.)                       │   │
│  └────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────────────────┐
│  STEP 5: Limiting                                                  │
│  ┌────────────────────────────────────────────────────────────┐   │
│  │  Apply limit (e.g., top 20)                                │   │
│  └────────────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────────────┘
                            │
                            ▼
                    Track IDs Response
```

## 3. Структура хранилищ данных

```
┌─────────────────────────────────────────────────────────────────────┐
│                    In-Memory Stores                                  │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│  TrackStore                                                          │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  tracks: map[string]*Track                                   │  │
│  │    └─ track_id → {TrackID, ArtistID, Genres, ReleaseTS, ...}│  │
│  │                                                               │  │
│  │  genreIndex: map[string]map[string]struct{}                   │  │
│  │    └─ genre → {track_id1, track_id2, ...}                    │  │
│  │                                                               │  │
│  │  artistIndex: map[string]map[string]struct{}                 │  │
│  │    └─ artist_id → {track_id1, track_id2, ...}                │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│  UserProfileStore                                                   │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  profiles: map[string]*UserProfile                             │  │
│  │    └─ user_id → {                                            │  │
│  │         UserID                                                │  │
│  │         GenreListenCount: map[string]int                     │  │
│  │           └─ genre → count                                   │  │
│  │         ArtistListenCount: map[string]int                    │  │
│  │           └─ artist_id → count                               │  │
│  │         ListenedTracks: map[string]struct{}                 │  │
│  │           └─ track_id → {}                                  │  │
│  │       }                                                       │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│  GlobalStatsStore                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  playCounts: map[string]int                                  │  │
│  │    └─ track_id → all-time play count                        │  │
│  │                                                               │  │
│  │  monthlyCounts: map[string]int                              │  │
│  │    └─ track_id → current month play count                   │  │
│  │                                                               │  │
│  │  monthlyCache: *monthlyChartCache                            │  │
│  │    └─ {tracks: [], monthKey: "2025-12", expiresAt: ...}    │  │
│  │      (TTL: 1 minute)                                        │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
                            │
                            │ Periodic Backup (every 5min)
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│  MinIO Backup Store                                                  │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  BackupData {                                                 │  │
│  │    Tracks: map[string]*Track                                  │  │
│  │    UserProfiles: map[string]*UserProfile                      │  │
│  │    GlobalStats: map[string]int                                │  │
│  │    MonthlyStats: map[string]int                               │  │
│  │    Timestamp: time.Time                                       │  │
│  │  }                                                            │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

## 8. Кеширование месячных чартов

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Monthly Charts Caching                            │
└─────────────────────────────────────────────────────────────────────┘

GET /charts/top Request
         │
         ▼
┌──────────────────┐
│ Check Cache      │
│ - tracks != nil? │
│ - monthKey match?│
│ - not expired?   │
└────────┬─────────┘
         │
         ├─── Valid? ────► YES ────► Return Cached Result
         │
         ▼ NO
┌──────────────────┐
│ Get Current      │
│ Month Key        │
│ (YYYY-MM)        │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Sort monthly     │
│ Counts by        │
│ play_count       │
│ (descending)     │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Take Top N       │
│ Tracks           │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Cache Result     │
│ - tracks         │
│ - monthKey       │
│ - expiresAt      │
│   (now + 1min)   │
└────────┬─────────┘
         │
         ▼
    Return Result

Cache Invalidation Triggers:
  - IncrementPlayCount() called
  - Month changed
  - Cache expired
```

# UI для создания маршрутов - Документация

## Что реализовано

### Страница создания маршрута (`/routes/create`)

Полнофункциональная страница для создания музыкальных маршрутов с интерактивной картой.

#### Компоненты

1. **CreateRoutePage** (`pages/create-route/ui/page.tsx`)
   - Главная страница с формой создания маршрута
   - Двухколоночный layout: форма слева, карта справа
   - Список точек маршрута внизу

2. **RouteMap** (`pages/create-route/ui/route-map.tsx`)
   - Интерактивная карта на базе Leaflet
   - Клик по карте добавляет новую точку
   - Отображение всех точек маршрута
   - Автоматическое масштабирование при добавлении точек

3. **PointEditor** (`pages/create-route/ui/point-editor.tsx`)
   - Редактор для каждой точки маршрута
   - Настройка названия, описания, радиуса активации
   - Выбор трека для точки
   - Удаление точки

4. **TrackSelector** (`pages/create-route/ui/track-selector.tsx`)
   - Модальное окно для выбора трека
   - Поиск треков по названию
   - Отображение обложек и артистов

#### Функциональность

- ✅ Создание маршрута с названием, описанием, городом, страной
- ✅ Добавление точек на карте кликом
- ✅ Редактирование точек (название, описание, радиус, трек)
- ✅ Выбор треков для точек через поиск
- ✅ Теги для маршрута
- ✅ Настройка публичности и линейности маршрута
- ✅ Валидация формы (название и минимум одна точка с треком)
- ✅ Сохранение через API Gateway

## Использование

### Навигация

Страница доступна по адресу: `/routes/create`

Кнопка "Создать маршрут" добавлена в header (видна только для авторизованных пользователей).

### Процесс создания маршрута

1. Заполните основную информацию:
   - Название маршрута (обязательно)
   - Описание (опционально)
   - Город и страна (опционально)
   - Теги (опционально)

2. Добавьте точки на карте:
   - Кликните на карте в нужном месте
   - Точка автоматически добавится

3. Настройте каждую точку:
   - Нажмите "Развернуть" на точке
   - Добавьте название и описание
   - Настройте радиус активации (по умолчанию 50м)
   - Выберите трек через кнопку "Выбрать трек"

4. Сохраните маршрут:
   - Кнопка "Сохранить маршрут" активна только если:
     - Заполнено название
     - Есть хотя бы одна точка
     - У всех точек выбран трек

## API интеграция

Все запросы идут через API Gateway (`http://localhost:8080`):

- `POST /api/v1/routes` - создание маршрута
- `GET /api/v1/tracks/search` - поиск треков для точек

## Стилизация

Карта использует темную тему, соответствующую дизайну приложения. Стили Leaflet настроены в `global.css`.

## Известные ограничения

1. **Геолокация пользователя**: Пока не реализовано автоматическое определение текущего местоположения для центрирования карты
2. **Перетаскивание точек**: Точки нельзя перемещать на карте (только удалять и добавлять новые)
3. **Предпросмотр маршрута**: Нет визуализации линии между точками
4. **Валидация координат**: Нет проверки на дубликаты точек в одном месте
